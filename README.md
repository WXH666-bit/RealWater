# RealWater

一个本地运行的三维水体与轻量水族馆：摇晃、倾斜、滴水、溢出，也可以添加会游动的小鱼。使用 Vite、TypeScript、Three.js 与 WebGL2 GPU APIC 求解器。没有后台、账号、遥测或在线资产依赖。

## 运行

需要 Node.js 22.12+（已在 Node.js 24 验证）。

```powershell
npm ci
npm run dev
```

打开 http://localhost:5173 。默认绑定局域网，端口固定为 5173；如端口被占用，会直接报错，不会悄悄改用另一个端口。只在自己的受信任网络中运行开发服务器。

```powershell
npm test
npm run build
npm run preview
```

生产文件位于 `dist/`，可用任意静态服务器运行；直接双击 HTML 不支持 ES 模块与资产加载。当前项目不部署到云端。

## 操作（顶部工具栏）

顶部提供「移动、倾斜、滴水、旋转」模式，以及「加一滴、加水、暂停/继续、重置、体感」按钮。「加水」持续向当前缸口注水，再次点击停止；暂停、重置或切到后台也会停止。「设置」中可调水滴大小和画质，画质变更在点击「重置」后生效。手机窄屏时，工具栏在顶部排成两行。

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 摇晃 | 左键拖动容器 | 单指拖动容器 |
| 倾斜 | 按住 Shift 拖动 | 双指同向拖动 |
| 滴水 | 点击缸口，按住超过 300ms 持续加水 | 同左 |
| 360° 观察 | 选择「旋转」后拖动画面；也可拖动空白处或右键拖动，滚轮缩放 | 选择「旋转」后单指/双指拖动；捏合缩放 |
| 重置 | 双击缸口外的空白区域 | 双击空白区域 |
| 体感 | M 键（需要传感器） | 在缸口外长按 700ms 后松手，授权并以当前姿势校准；再长按可关闭 |

键盘：`1 / 2 / 3` 可固定移动、倾斜、滴水模式，`Escape` 回到自动手势模式。场景获得焦点后，方向键移动（倾斜模式下改变角度），`Enter` 滴水，`Space` 暂停，`R` 重置。`+ / -` 调整水滴大小；`Q` 循环切换画质并重置水体。倾角限制为 ±85°。手动拖动会结束体感控制，避免两种输入相互争抢。

视角可以水平绕行任意圈，并能从上方和下方观察；仅在正上方/正下方保留 2°，避免相机极点翻转。摇晃、倾斜、方向键和体感均按当前视角换算到世界坐标；转到背面后，同样向右拖动会沿相反的世界方向移动。仅转动视角不会移动容器、重置水体或改变重力。

页面以容器和水为主体，仅在顶部保留必要操作，没有侧栏或常驻数据面板。权限、容量等提示会短暂显示在工具栏下方，并支持屏幕阅读器。画质在启动时保守选择，不在交互过程中自动重建水体。粒子数量包含空中的水滴；离开画面的水回收后水量下降。达到粒子上限会停止加水，不删除原有水。

## 小小水族馆

水缸内部尺寸约为 52 × 28.8 × 26cm，宽度比原版增加 30%，初始仍为半缸水。顶部「生物」可以添加橙白条纹鱼、蓝色扁身鱼和黄色细身鱼，每次一条，最多 12 条；默认没有小鱼。

- 小鱼会摆尾巡游、避让同伴和缸壁，轻微随水流漂移。它们不反向推动流体，也不占用水粒子的容量。
- 暂停会同时冻结小鱼与水体，暂停期间仍可添加或清空生物。重置、切换画质后重置、图形上下文恢复会保留鱼种和数量，并重新安置。
- 倾倒和剧烈摇晃时优先在缸内寻找安全水域；必要时会直接重新安置小鱼。持续 0.5 模拟秒没有足够空间时自动收回，并合并提示；不会表现搁浅、死亡或在空气中游动。
- 「清空生物」只移除鱼群，不重置水体。刷新页面不保存鱼群；没有喂食、繁殖、养成或在线模型下载。
- 小鱼使用程序化三维图元，在水内折射光路中求交并计算遮挡、吸收与反射。浸水与避让采用有限采样的包围球近似，不是精确的鱼体动力学。

## 手机局域网与 HTTPS 体感

1. 手机和电脑连接同一个局域网，用终端显示的实际 Wi-Fi/以太网地址打开 `http://<电脑的局域网 IP>:5173`。虚拟网卡地址不一定可访问。此方式可测试触屏。
2. 手机体感通常需要 HTTPS；`http://localhost` 的安全上下文例外仅适用于电脑本机，不能替代手机的 HTTPS。
3. 从官方项目 https://github.com/FiloSottile/mkcert 安装 mkcert。由你决定是否信任其开发证书，执行：

```powershell
mkcert -install
New-Item -ItemType Directory -Force .cert
# 用实际局域网 IP 替换 192.168.1.20；IP 改变后重新生成证书。
mkcert -key-file .cert/localhost-key.pem -cert-file .cert/localhost.pem localhost 127.0.0.1 ::1 192.168.1.20
npm run dev:https
```

4. 使用 `mkcert -CAROOT` 找到根证书文件夹，仅把 **rootCA.pem 公钥证书** 安装到手机并按系统要求启用信任，绝不要拷贝或分享 `rootCA-key.pem` 或服务器私钥。iOS 还需在“设置 → 通用 → 关于本机 → 证书信任设置”中启用对应根证书；具体入口以系统版本为准。
5. 手机打开 `https://<该 IP>:5173`，确认没有证书错误，再点击顶部「体感」按钮开启并授权。也可在缸口外长按 700ms 后松手开启。无需、也不建议绕过浏览器证书警告。

`.cert/` 已加入忽略规则。没有证书时 `npm run dev:https` 会明确提示。权限被拒绝、没有方向传感器、没有加速度数据或传感器无响应时，页面保留触屏操作。不会自动修改系统证书信任或防火墙。

## 实现要点

- 世界坐标中的有限粒子池，以 GPU 纹理保存位置、速度和局部速度梯度。
- 每个粒子的水量由半缸实际体积除以初始化粒子数得到；滴水计数使用这个体积，避免网格取整后不同画质的加水量不一致。粒子水量守恒与重建几何体积误差分别检查。
- 三维交错 MAC 网格在二维纹理中铺开；半浮点加法混合实现加权粒子到网格传递。
- 按 52cm 宽桌面水缸定义尺寸（1 场景单位 = 20cm），重力相应换算，避免两米泳池尺度造成的慢动作。
- 重力、弱自由表面凝聚近似与固定 1/90 秒步进。压力和速度计算使用 Float32，采用加权 Jacobi 热启动（低/中 60 次、高 84 次），将单向密度源改为有速率上限、10% 容差带的体积恢复，只有内部水格允许负向补偿，避免收缩水面。APIC 局部速度梯度按模拟时间耗散，低/中档每个固定步保留约 82%，高档按网格间距平方缩放耗散率，不衰减整体平移；这会削弱网格尺度的细涡，不是精确的水黏度模型。保留 RK2 面流量输运及 APIC 动量传递，避免普通位置插值在倾倒时压缩粒子；仍有有限网格的体积误差。稀疏水滴根据邻近支持度连续退出网格耦合并按重力运动，缸外水滴不跟随隔着玻璃的内部流速。拥挤粒子采用有限的位置重分布，贴壁时补偿被玻璃截断的核体积，不增删粒子、不直接注入速度；严重重合时使用极小的确定性分离偏移。核体积补偿在倾斜时使用局部轴近似，仍不是精确几何体积约束。玻璃碰撞保留切向速度。
- 五块有限厚度的移动壁面参与压力边界和粒子扫掠碰撞；顶部开放，缸外粒子继续参与计算域内流体模拟，域外按弹道继续运动。
- 自由液面的零压力位置在液体和空气网格间插值，压力求解与速度投影使用相同距离比例，减少整格空气边界造成的静置起伏。最小距离比例为 0.1，以限制极薄液体格的数值刚性；仍是有限网格近似。
- 贴壁重建、表面过滤和法线使用同一份镜像邻域支持度与速度，避免将玻璃边缘的密集水体误判成稀疏水滴。原始隐式场使用 RGBA16F 保存这些信息，过滤与历史场仍为 R16F，因此会增加原始场的显存占用。
- 密集邻域加入占据约束，防止粒子加权中心偏移时在水体内部生成假凹洞。支持度低的水滴仍使用原有分离判定；这属于表面重建近似，可能填平接近重建尺度的密集小空隙，不是空气相模拟。
- 水内光线沿玻璃掠射时，使用未被玻璃裁剪的液体场决定步长，用裁剪后的场判断出口；步长小于玻璃厚度，避免贴底光线因距离底板太近而提前耗尽追踪预算、突然切换备用颜色。
- 用邻近粒子的加权位置重建世界坐标中的连续三维隐式表面（Zhu–Bridson 方法）。GPU 在体积纹理中计算并平滑该表面，再求相机射线与表面的交点、法线和实际占据厚度，结合折射、菲涅耳反射、厚度吸收和玻璃分层合成。粒子的屏幕圆面仅用于加速求交，不作为可见水面；离开重建区域的远处飞溅仍用有曲面法线和深度的球面求交显示。
- 液面重建使用更宽的邻域和按邻域密度变化的半径：整体水面平顺，小水滴保留独立体积。额外累计距离平方，拒绝分离水滴之间的虚假连接。密集液面做空间平滑；接近静止的区域使用 0.1 秒时间尺度抑制采样闪动，局部速度达到 0.16 场景单位/秒或形状突变时取消历史混合。该处理不修改模拟速度，但会平滑非常缓慢的细波。按折射率 1.333 追踪入水和出水界面，光路采样与场景共用的世界坐标背景。
- 水体内部最多追踪四次界面相交，逐段累计吸收和透射，继续追踪剩余反射能量；低于 0.5% 的剩余能量提前结束。超过预算的剩余路径使用背景近似，不是无限次光线追踪。表面反射与折射共用世界坐标背景，避免把尚在水内的反射直接当成天空高光。
- 控制器入口统一用于鼠标、触屏、手机传感器和可选的 WebMCP `reset_water` / `add_water_drop`。
- 低、中档共享最低物理网格精度，低档降低液面重建与画面分辨率；高档增加物理粒子和网格精度。较粗的低档物理网格曾导致薄玻璃附近体积漂移，已移除。运行时只降低渲染分辨率。后台暂停，恢复不补算离开期间的时间。显卡上下文恢复会重置水体。
- 每帧最多执行 8 个固定子步，使 12～20 FPS 下仍能按实际时间推进，避免低帧率被误认为水很黏。超过 250ms 的中断丢弃时间，防止恢复时爆发补算。表面重建覆盖完整容器活动范围和近处飞溅，较旧版减少约一半体积网格；稀疏水滴之间提高融合门槛，减少拉丝状假连接。

这是交互式流体近似，不是工程 CFD 软件：表面张力使用网格尺度的凝聚近似，不解完整微观毛细曲率；不模拟空气、气泡、泡沫、精确焦散、粘附水膜和台面积水。粗网格、有限压力迭代和粒子重建会带来体积与表面误差，弱设备还可能降低细节和实际模拟速度。

## 开发与验证

`http://localhost:5173/diagnostics` 是独立的开发验证入口，可运行一分钟静置、连续摇晃、两分钟摇晃、倾倒、加水及容量拒绝场景，并查看粒子收支、非有限值、垂向范围、速度、画质、帧率及 GPU 纹理数量。深度、法线和厚度显示用于检查液面重建。测试通过分批执行固定物理步加速，因此测试期间的显示帧率不代表正常交互性能。后台的浏览器页面也可能受帧调度节流，性能应在前台正常交互时测量。正式构建仅有产品工具栏，不包含诊断面板；旧的 `?qa=1` 参数不会开启诊断 UI。

测试覆盖初始化、12～240 FPS 及交替慢帧下的固定步进、视角方向，以及单滴球面、平整液面、邻近水滴融合和拉开后的分离。另有回归检查验证粒子分布造成的小鼓包减少、整体波峰仍被保留。诊断入口的「水滴体积」会在水滴入水前暂停，「液面形态」会在可重复的摇晃后暂停，便于旋转比较；`simulationRate` 是模拟秒与实际秒之比，正常运行应接近 1，批量测试期间会大于 1。GPU 支持计时扩展时，还显示单帧水面渲染耗时（不包含物理求解，暂停时会复用重建结果，不能换算成整页帧率）。图形、碰撞、注水及 WebMCP 通过真实浏览器检查。真机手机性能与传感器校准必须在实际手机上验证，调整浏览器视口仅能证明响应式布局。

诊断页的「速度传递基准」用实际 GPU 着色器核对解析平移、旋转与剪切场；「液面高度采样」暂停当前场景并读取正立、居中容器内的 33×19 个液面交点。静置测试在 60 模拟秒处暂停，便于比较同一终点，采样不适用于已经倾倒或移动的容器。

视角方向测试另外覆盖正面、背面、两侧、整圈归位和仰视，检查屏幕方向与世界平移/倾斜保持一致。浏览器实测记录见 [VALIDATION.md](VALIDATION.md)。APIC 方法及来源见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

第三方算法来源和许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

水族馆开发验证：诊断页提供「水族馆 GPU 基准」和「水族馆整帧耗时」。前者检查实际 GPU 鱼群更新、数量上限、缺水收回、随流漂移、遮挡和吸收；后者比较同画质、同分辨率的 0 / 12 条鱼，包含物理与水面绘制，但不包含浏览器合成，不能替代手机真机 FPS。批量测试中的 CPU 提交时间包含同步 GPU 读回等待，不能与 GPU 时间直接相加。开发物理场景会清空鱼群；倾倒场景观察 20 模拟秒，避免将 8 秒处尚未落下的飞溅当作持续滞留。
